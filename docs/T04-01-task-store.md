# T04-01 — Agent 本地任务数据库与状态机

> 仓库：`CiBeDerORG/EasyHostAgent`；分支：`feat/server-app-lifecycle`。本任务为 M4 后续并发调度与 Deploy 执行器提供持久化基础。

## 本轮交付

- 使用纯 Go SQLite 驱动持久化任务、幂等请求摘要、状态、退出码、起止时间、结果和字节日志游标。
- 客户端生成的 `task_id` 是幂等键；同 ID 同请求返回原任务，不重复插入；同 ID 不同请求返回冲突。
- 请求正文使用 AES-256-GCM 加密，敏感参数不以明文写入 SQLite；独立密钥文件为 0600，数据库文件为 0600，数据目录必须为 0700。
- 状态机拒绝非法状态跳转；Agent 重启时把 `accepted/running/cancelling` 任务标记为 `interrupted`，不恢复执行、不回滚。
- 日志按字节偏移分页，最大返回 256 KiB，保证响应是有效 UTF-8；密钥跨日志分块出现时使用加密的待处理尾部缓冲，避免把完整密钥写入日志；任务消息与结果也会脱敏。
- 增加配对授权保护的只读任务列表、任务状态和日志查询 API，供控制端在响应丢失后按任务 ID 查询结果。

## 当前边界

本任务**没有**启用 `POST /v1/tasks` 提交或执行接口；在 T04-03 的白名单执行器接入前，不能把一个“accepted”任务伪装成已开始执行。并发调度与取消归 T04-02，脚本/Compose 执行归 T04-03。

## 验收覆盖

- SQLite 重开后的任务持久化与中断状态。
- 同 ID 幂等提交与请求冲突。
- 敏感请求加密存储，公开任务响应不包含请求密钥。
- 状态机非法跳转拒绝、任务日志保留。
- 密钥在日志分块边界处的脱敏。
- 分页游标、UTF-8 多字节日志偏移。
- HTTPS 任务查询必须具备已配对 Controller 授权。

CI 由本次提交自动触发；结果尚未核验时，后续任务开始前先检查本次运行，失败优先修复。
